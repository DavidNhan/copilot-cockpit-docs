# FAQ

## Ist Copilot Cockpit offizielle GitHub Dokumentation?

Nein. Es ist eine unabhaengige Referenz auf Basis oeffentlicher Quellen und praktischer Erfahrung.

## Brauche ich spezielle Rollen, um die Seite zu lesen?

Nein. Die Seite ist als Referenz fuer breite Zielgruppen gedacht.

## Welche Perspektive ist fuer Security relevant?

Security als primare Seite, plus Tower fuer Governance und Controls.

## Wo sehe ich Aenderungen ueber die Zeit?

In Flight Log.

## Wie pruefe ich Rollout-Readiness?

Mit Pre-Flight und den verlinkten Perspektiven.
