# Navigation and Workflows

## Hauptnavigation

Die Perspektiven sind bewusst getrennt, damit Informationen fokussiert bleiben.

Empfohlener Ablauf:

1. Terminal
2. Jet Bridge
3. Cockpit
4. Runway, Tower, Security

## Typische User Workflows

### Workflow A: Feature verstehen

1. Im Cockpit ein Instrument waehlen
2. Detailansicht oeffnen
3. Bei Bedarf zu Security oder Tower springen

### Workflow B: Modellwahl vorbereiten

1. Runway oeffnen
2. Modelle nach Bedarf vergleichen
3. Relevante Governance-Aspekte in Tower pruefen

### Workflow C: Rollout vorbereiten

1. Pre-Flight Checkliste durchgehen
2. Flight Log auf relevante Aenderungen pruefen
3. Teamentscheidung dokumentieren

## Such- und Deep-Linking

- Suche nutzen fuer direkte Treffer ueber mehrere Inhalte hinweg
- Deep Links nutzen, um auf konkrete Details zu verweisen
