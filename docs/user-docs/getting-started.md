# Getting Started

## Was ist Copilot Cockpit?

Copilot Cockpit ist eine interaktive Referenzseite fuer GitHub Copilot. Die Inhalte sind als Luftfahrt-Metapher organisiert.

## In 5 Minuten starten

1. Oeffne die Seite im Browser.
2. Starte mit Terminal fuer Einstieg und Setup.
3. Gehe zu Jet Bridge fuer Prompt- und Workflow-Muster.
4. Nutze Cockpit als zentrale Feature-Uebersicht.
5. Nutze Runway, Tower und Security fuer Vertiefung.

## Welche Seite fuer welchen Zweck?

- Terminal: Einstieg, Plans, Setup
- Jet Bridge: Prompting und Arbeitsmuster
- Ramp: Agenten, MCP, Tooling
- Cockpit: Gesamtueberblick aller Instrumente
- Runway: Modelle und Routing
- Tower: Governance und Admin Controls
- Security: Threats und Gegenmassnahmen
- Flight Log: Changelog und Historie
- Pre-Flight: Readiness Checklist
- Wiring: Verbindungsdiagramm

## Tipps fuer den Alltag

- Nutze Deep Links fuer direkte Kontexte.
- Nutze die Suche fuer schnelle Spruenge.
- Nutze Flight Log bei Aenderungen als Einstieg in Impact-Analysen.
