# Quality Rubric

## Scoring Scale (0-5)

- 0: absent
- 1: minimal
- 2: partial
- 3: good
- 4: very good
- 5: best-practice and evidence-backed

## Weighted Criteria

| Criterion | Weight |
| --- | ---: |
| Completeness | 25 |
| Correctness | 25 |
| Traceability | 20 |
| Maintainability | 15 |
| Verifiability | 15 |

## Formula

`Total Score (%) = sum((points / 5) * weight)`

## Hard Exit Criteria

1. Total score >= 90
2. No criterion below 4
3. Completeness and Correctness >= 4.5
