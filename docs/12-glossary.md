# 12 Glossary

## Purpose

Shared glossary to keep terminology consistent across all chapters.

## Terms

- Instrument: A mapped Copilot capability in the cockpit model.
- Perspective: A focused page context (for example Terminal, Runway, Tower).
- Deep Link: URL fragment or route that opens a specific in-page context.
- Catalog: JSON file acting as source-of-truth content.
- Integrity Check: Validation that references and required fields remain valid.
- Verification Required: Marker indicating entries need manual source verification.
- Quality Gate: Mandatory check before merge or release.
- ADR: Architecture Decision Record.
- Runbook: Procedural response guide for operational incidents.
- SLI/SLO: Reliability indicators and objective targets.

## Terminology Rule

When introducing a new cross-cutting term:

1. Add it to this glossary
2. Use the same wording in all affected chapters
3. Mention changes in `changelog.md`
