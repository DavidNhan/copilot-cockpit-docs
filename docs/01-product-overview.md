# 01 Product Overview

## Purpose

Copilot Cockpit is an interactive reference for GitHub Copilot capabilities using an aviation cockpit metaphor.

## Scope

In scope:

- Feature mapping across perspectives
- Data-driven technical content
- Governance and security context
- Operational and testing guidance

Out of scope:

- Proprietary internal roadmaps
- Non-public telemetry

## Audience

- Platform and solution architects
- Engineering leads
- Security and governance stakeholders
- Developer enablement teams

## Product Characteristics

- Static multi-page web application
- Vanilla JavaScript runtime
- JSON-driven content model
- Browser-based navigation and deep links

## Perspective Model

- Terminal: onboarding and first steps
- Jet Bridge: prompt and workflow patterns
- Ramp: agents and operational tooling
- Cockpit: central instrument board
- Runway: model catalog and routing context
- Tower: governance and controls
- Security: threats and countermeasures
- Flight Log / Pre-Flight / Wiring: utility and system support views
