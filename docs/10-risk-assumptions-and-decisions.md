# 10 Risk, Assumptions, and Decisions

## Purpose

This chapter centralizes project risks, key assumptions, and decision governance.

## Top Risks

1. Taxonomy drift across data catalogs
2. Broken deep links due to ID changes
3. Stale governance/security references
4. Missing ownership for critical doc sections

## Assumptions

1. Public sources remain available and stable
2. Reviewers for architecture/security/operations are available
3. Test suites continue to represent critical product behavior

## Decision Governance

Architecture-impacting decisions should be captured as ADRs.

ADR rules:

1. One decision per ADR
2. Include context, options, decision, consequences
3. Link affected chapters and tests
